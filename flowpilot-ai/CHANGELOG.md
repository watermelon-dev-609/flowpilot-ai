# 更新日志

本文档记录 FlowPilot AI 的重要版本变化。

## v1.1.0 - 2026-09-14

### 新增

- 新增运营工作台首页，替代早期项目说明型首页。
- 新增全局导航，统一连接规则中心、GEO 研究、内容适配、发布队列、GEO 监测、引用准备度和内容日历。
- 新增规则中心本地持久化、平台选择、来源复核和动态规则更新计划。
- 新增真实 GEO 监测最小闭环，区分品牌提及、页面检索和来源引用。
- 新增 GEO 监测数据概览、监测记录页、复核页、会话页和 Markdown 周报导出。
- 新增 GEO Research 与规则中心、监测数据联动。
- 新增选题优先级、难度和平台适配评分。
- 新增内容适配页面，支持母稿、多平台版本、平台策略、引用准备提示和发布建议。
- 新增发布队列页面，支持发布准备、失败原因和状态展示。
- 新增引用准备度页面，用于检查内容被 AI 检索和引用前的基础条件。
- 新增内容日历独立页面，支持关键词、状态、平台、负责人、优先级和日期范围筛选。

### 改进

- 页面可见文案统一中文化，避免把简历映射信息直接放入产品界面。
- 增加统一 API 响应契约、异步数据状态模型和数据状态展示组件。
- 将选题池本地仓储抽离为独立层，减少页面与浏览器存储的耦合。
- 将内容日历从内容适配页面中拆出，降低单页复杂度。
- 增加项目计划记录，持续沉淀开发过程、验证结果、问题和风险。

### 验证

- 前端完整测试通过：33 个测试文件，115 条用例通过。
- 前端生产构建通过。
- 本地页面访问检查通过：
  - `/content-calendar` 返回 HTTP 200。
  - `/content-adaptation` 返回 HTTP 200。
  - `/geo-research` 返回 HTTP 200。

### 已知限制

- 当前主要使用浏览器本地存储，尚未切换为正式后端数据库。
- 筛选条件尚未写入 URL，刷新页面后不会保留。
- 规则更新和 GEO 监测仍是最小闭环，真实平台数据采集需要后续接入 API 或半自动复核流程。
- 发布队列仍偏发布准备与状态管理，尚未接入真实平台发布适配器。
- 不承诺 GEO 排名，也不承诺一定被任何 AI 平台引用。
