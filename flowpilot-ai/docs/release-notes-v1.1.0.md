# FlowPilot AI v1.1.0 Release Notes

发布日期：2026-09-14

## 版本定位

v1.1.0 是 FlowPilot AI 的第一个可验收版本，完成了企业 GEO 内容运营工作台的前端最小闭环。

这个版本聚焦三个问题：

1. 如何围绕企业品牌、产品和 GEO 目标形成选题与内容计划。
2. 如何把内容适配到多个媒体平台，并进入发布准备流程。
3. 如何用真实监测记录和引用准备度检查，避免只生成内容、不复盘效果。

## 主要更新

- 运营工作台首页。
- 全局导航。
- 规则中心与动态规则更新计划。
- 真实 GEO 监测最小闭环。
- GEO 监测周报导出。
- GEO Research 与规则、监测数据联动。
- 选题优先级、难度、平台适配评分。
- 内容适配工作台。
- 发布队列。
- 引用准备度检查。
- 内容日历与筛选系统。

## 验收结果

- 前端完整测试通过：33 个测试文件，115 条用例通过。
- 前端生产构建通过。
- 关键页面 HTTP 检查通过：
  - `/content-calendar`
  - `/content-adaptation`
  - `/geo-research`

## 升级说明

本版本仍以本地演示和作品集展示为主，不建议直接接入真实企业账号进行无人值守发布。

如果要进入真实业务使用，建议优先补齐：

- 后端数据库。
- 用户与权限体系。
- 平台账号授权与密钥加密。
- 发布适配器。
- GEO 监测数据来源复核流程。
- 操作审计与日志脱敏。

## 不承诺内容

FlowPilot AI 不承诺 GEO 排名，不承诺一定被 ChatGPT、DeepSeek、豆包、文心一言、腾讯元宝等 AI 平台引用。

本版本只承诺提升内容的结构化、可复核性、引用准备度和持续监测能力。
